# 1.3 艾森斯坦判别

## 艾森斯坦判别法

<Callout type="default" emoji="📐">
**形式 1（一般形式）**：设 $f(x) = a_n x^n + \cdots + a_1 x + a_0$ 是整系数多项式，若存在素数 $p$ 使得

$$p \nmid a_n;\quad p \mid a_{r-1}, \ldots, a_1, a_0;\quad p^2 \nmid a_0,$$

则 $f(x)$ 有一个**次数 $\geq r$ 且在有理数域上不可约**的因式。
</Callout>

<Callout type="default" emoji="📐">
**形式 2（不可约判别）**：设 $f(x) = a_n x^n + \cdots + a_0$ 是 $n$ 次整系数多项式，若存在素数 $p$ 使得

$$p \nmid a_n;\quad p \mid a_{n-1}, \ldots, a_1, a_0;\quad p^2 \nmid a_0,$$

则 $f(x)$ 在有理数域上**不可约**。
</Callout>

<Callout type="default" emoji="📐">
**形式 3（无有理根时）**：设整系数多项式 $f(x) = a_n x^n + \cdots + a_0$ 没有有理根，若有素数 $p$ 满足

$$p \nmid a_n;\quad p \mid a_{n-2}, \ldots, a_0;\quad p^2 \nmid a_0,$$

则 $f(x)$ 在有理数域上不可约。
</Callout>

## 平移定理

<Callout type="default" emoji="📐">
**平移定理**：设 $f(x) \in P[x]$，$a \in P$，则 $f(x)$ 与 $f(x+a)$ 在 $P[x]$ 中的**可约性相同**。

**证明（双向）**：

$(\Rightarrow)$ 若 $f(x) = p(x)q(x)$，则 $f(x+a) = p(x+a)q(x+a)$，故 $f(x+a)$ 也可约。

$(\Leftarrow)$ 若 $f(x+a) = p(x)q(x)$，则 $f(x) = p(x-a)q(x-a)$，故 $f(x)$ 也可约。$\blacksquare$
</Callout>

<Callout type="warning" emoji="💡">
**使用策略**：当直接对 $f(x)$ 应用艾森斯坦失败时，尝试对 $f(x+a)$（通常取 $a=1$ 或 $a=-1$）应用艾森斯坦，再利用平移定理得出 $f(x)$ 不可约。
</Callout>

## 例题

**例题**：判断以下多项式在有理数域是否可约：

**(1)** $x^n + 2$

**解答**：取素数 $p = 2$：$2 \nmid 1$（首项系数），$2 \mid 2$（常数项），$4 \nmid 2$。由形式 2，$x^n + 2$ 在 $\mathbf{Q}$ 上不可约。$\blacksquare$

---

**(2)** $x^3 + x^2 - 3x + 2$

**解答**：低次多项式（$n \leq 3$）在 $\mathbf{Q}$ 上可约当且仅当有有理根。

由有理根定理，候选有理根为 $\pm 1, \pm 2$。代入验算：

$$f(1) = 1+1-3+2 = 1 \neq 0,\quad f(-1) = -1+1+3+2 = 5 \neq 0,$$
$$f(2) = 8+4-6+2 = 8 \neq 0,\quad f(-2) = -8+4+6+2 = 4 \neq 0.$$

无有理根，故 $x^3 + x^2 - 3x + 2$ 在 $\mathbf{Q}$ 上**不可约**。$\blacksquare$

---

**(3)** $x^5 + 5x^3 + 1$

**解答**：令 $g(x) = f(x+1) = (x+1)^5 + 5(x+1)^3 + 1$，展开得

$$g(x) = x^5 + 5x^4 + 10x^3 + 10x^2 + 5x + 1 + 5x^3 + 15x^2 + 15x + 5 + 1$$
$$= x^5 + 5x^4 + 15x^3 + 25x^2 + 20x + 7.$$

取 $p = 5$：$5 \nmid 1$，$5 \mid 5, 15, 25, 20, 7$（注意 $5 \nmid 7$）……

实际上常数项为 $1+5+1=7$，不被 $5$ 整除，此路不通。改取 $g(x) = f(x-1)$：

$$g(x) = (x-1)^5 + 5(x-1)^3 + 1$$

展开后常数项为 $(-1)^5 + 5(-1)^3 + 1 = -1 - 5 + 1 = -5$，且首项系数为 $1$。

取 $p=5$：$5 \nmid 1$，验算其余系数均被 $5$ 整除，$25 \nmid (-5)$，由形式 2 知 $g(x)$ 不可约，故 $f(x)$ 不可约。$\blacksquare$

---

**(7)** $\Phi_p(x) = x^{p-1} + x^{p-2} + \cdots + x + 1$，其中 $p$ 是素数（第 $p$ 个分圆多项式）。

**解答**：注意 $\Phi_p(x) = \dfrac{x^p - 1}{x - 1}$。令 $g(x) = \Phi_p(x+1) = \dfrac{(x+1)^p - 1}{x}$。

由二项式定理，$(x+1)^p - 1 = \sum_{k=1}^{p} \dbinom{p}{k} x^k$，故

$$g(x) = \sum_{k=1}^{p} \binom{p}{k} x^{k-1} = x^{p-1} + \binom{p}{p-1}x^{p-2} + \cdots + \binom{p}{2}x + p.$$

取素数 $p$：首项系数 $1$ 不被 $p$ 整除；其余系数 $\dbinom{p}{k}$（$1 \leq k \leq p-1$）均被 $p$ 整除；常数项 $p$ 被 $p$ 整除但 $p^2 \nmid p$。

由艾森斯坦判别法，$g(x)$ 在 $\mathbf{Q}$ 上不可约，故 $\Phi_p(x)$ 在 $\mathbf{Q}$ 上不可约。$\blacksquare$
