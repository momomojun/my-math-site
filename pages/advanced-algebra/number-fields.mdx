# 1.1 数环与数域

## 基本概念

<Callout type="info" emoji="📌">
**定义（数环）**

设 $S$ 是复数集 $\mathbf{C}$ 的一个非空子集，如果对于 $S$ 中任意两个数 $a, b$ 来说，$a+b,\ a-b,\ ab$ 都在 $S$ 内，那么称 $S$ 是一个**数环**。
</Callout>

<Callout type="info" emoji="📌">
**定义（数域）**

设 $F$ 是一个数环，如果 $F$ 含有非零单位元，且对于 $F$ 中任意两个数 $a, b$（$b\neq 0$）来说，$a+b,\ a-b,\ ab,\ \dfrac{a}{b}$ 都在 $F$ 内，那么称 $F$ 是一个**数域**。
</Callout>

常见数集的判断：

|      | 复数 $\mathbf{C}$ | 实数 $\mathbf{R}$ | 有理数 $\mathbf{Q}$ | 整数 $\mathbf{Z}$ | 自然数 $\mathbf{N}$ |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 数环 | ✔ | ✔ | ✔ | ✔ | ❌ |
| 数域 | ✔ | ✔ | ✔ | ❌ | ❌ |

<Callout type="default" emoji="📐">
**命题**：任何数域都包含有理数域；有理数域 $\mathbf{Q}$ 是最小的数域。
</Callout>

## 整除性与数域无关

<Callout type="info" emoji="📌">
**定理（带余除法）**

设 $f(x), g(x) \in K[x]$，且 $g(x) \neq 0$，则在 $K[x]$ 中存在唯一的一对多项式 $h(x), r(x)$，使得

$$f(x) = h(x)\,g(x) + r(x), \quad \deg r(x) < \deg g(x).$$

其中 $f(x), g(x)$ 分别叫做**被除式**、**除式**，$h(x), r(x)$ 分别叫做**商式**、**余式**。
</Callout>

<Callout type="default" emoji="📐">
**定理**：整除性不随数域扩大而改变，即整除性与数域无关。

**推论**：多项式的最大公因式、互素性、重因式，也与数域无关。

**注意**：多项式的**可约性**和根的**重数**会随数域改变。
</Callout>

## 例题

**例题**：设 $f(x)$ 是有理系数多项式，且 $1+\sqrt{2}$ 是 $f(x)$ 的根，证明 $1-\sqrt{2}$ 也是 $f(x)$ 的根。

**解答**：构造有理系数多项式

$$p(x) = (x-1-\sqrt{2})(x-1+\sqrt{2}) = (x-1)^2 - 2 = x^2 - 2x - 1.$$

一方面，$p(x)$ 的两个根均为无理数，所以 $p(x)$ 在有理数域上不可约；

另一方面，$p(x)$ 与 $f(x)$ 有公共实数根 $1+\sqrt{2}$，所以它们在实数域上不互素。

根据互素性不随数域扩大而改变，所以 $f(x)$ 与 $p(x)$ 在有理数域上也不互素，

从而 $p(x) \mid f(x)$，于是 $1-\sqrt{2}$ 也一定是 $f(x)$ 的根。$\blacksquare$

## 习题

**习题 1**：设 $f(x)$ 是一个 $m\ (m \geq 1)$ 次整系数多项式，$n$ 是正整数，且 $\sqrt[n]{2}$ 是 $f(x)$ 的根，证明 $m \geq n$。

**解答**：考虑整系数多项式 $g(x) = x^n - 2$，显然 $\sqrt[n]{2}$ 也是 $g(x)$ 的根，

所以 $x - \sqrt[n]{2}$ 是 $f(x)$ 与 $g(x)$ 的公因式，即它们在实数域上不互素，从而在有理数域上也不互素。

由艾森斯坦判别法知 $g(x)$ 在有理数域上不可约，从而 $g(x) \mid f(x)$，又 $f(x) \neq 0$，

所以 $\partial(g(x)) \leq \partial(f(x))$，即 $m \geq n$。$\blacksquare$

---

**习题 2**：证明实数域作为有理数域上的线性空间是无限维的。

**解答**：只需证对任意正整数 $n$，向量组 $1, \sqrt[n]{2}, \sqrt[n]{2^2}, \ldots, \sqrt[n]{2^{n-1}}$ 在 $\mathbf{Q}$ 上线性无关。

假设存在有理数 $a_0, a_1, \ldots, a_{n-1}$ 使得

$$a_0 + a_1 \sqrt[n]{2} + a_2 \sqrt[n]{2^2} + \cdots + a_{n-1}\sqrt[n]{2^{n-1}} = 0,$$

则 $\sqrt[n]{2}$ 是有理系数多项式 $f(x) = a_0 + a_1 x + \cdots + a_{n-1}x^{n-1}$ 的一个根。

由习题 1 知，若 $f(x) \neq 0$ 则 $\deg f \geq n$，但 $\deg f \leq n-1$，矛盾。故 $f(x) = 0$，即 $a_0 = a_1 = \cdots = a_{n-1} = 0$。

这说明该向量组线性无关，故实数域作为 $\mathbf{Q}$ 上的线性空间是无限维的。$\blacksquare$
