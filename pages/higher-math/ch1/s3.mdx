# 1.3 函数的极限

## 1.3.1 函数极限概念

<Def num={1} title="函数极限（ε-δ 定义，x → a）">
设 $f(x)$ 在点 $a$ 的某去心邻域 $\mathring{U}(a)$ 内有定义。若对任意 $\varepsilon > 0$，存在 $\delta > 0$，使当 $0 < |x-a| < \delta$ 时有
$$|f(x) - L| < \varepsilon,$$
则称 $L$ 为 $f(x)$ 当 $x \to a$ 时的**极限**，记作 $\lim_{x\to a} f(x) = L$。
</Def>

<Def num={2} title="单侧极限">
**左极限**：$\lim_{x\to a^-} f(x) = L^-$（仅考虑 $0 < a - x < \delta$）；

**右极限**：$\lim_{x\to a^+} f(x) = L^+$（仅考虑 $0 < x - a < \delta$）。
</Def>

<Thm num={1} title="极限存在的充要条件">
$$\lim_{x\to a}f(x) = L \iff f(a^-) = f(a^+) = L.$$
</Thm>

<Def num={3} title="函数极限（x → ∞）">
若对任意 $\varepsilon > 0$，存在 $X > 0$，使当 $|x| > X$ 时有 $|f(x) - L| < \varepsilon$，则记 $\lim_{x\to\infty}f(x) = L$。
</Def>

## 1.3.2 函数极限性质

<Thm num={2} title="函数极限的性质">
设 $\lim_{x\to a}f(x) = L$，则：

1. **唯一性**：$L$ 唯一；
2. **局部有界性**：$f$ 在 $a$ 的某去心邻域内有界；
3. **保号性**：若 $L > 0$，则 $\exists\,\delta > 0$，$0 < |x-a| < \delta$ 时 $f(x) > 0$；
4. **保序性**：若 $f(x) \leq g(x)$（$x$ 在 $a$ 附近），则 $\lim f \leq \lim g$。
</Thm>

<Rmk>
极限只关心 $x$ **趋近** $a$ 时的行为，与 $f(a)$ 是否存在、取何值**无关**。
</Rmk>

## 1.3.3 函数极限典例

<Problem num="例 1.3.1">
用 ε-δ 定义证明 $\lim_{x\to 2}(3x^2 - 4) = 8$。

<Solution>
$|(3x^2 - 4) - 8| = 3|x^2 - 4| = 3|x-2||x+2|$。

当 $|x - 2| < 1$ 时，$|x+2| < 5$，故 $|(3x^2-4)-8| < 15|x-2|$。

对任意 $\varepsilon > 0$，取 $\delta = \min\!\left\{1,\,\dfrac{\varepsilon}{15}\right\}$，则当 $0 < |x-2| < \delta$ 时有 $|(3x^2-4)-8| < \varepsilon$。$\blacksquare$
</Solution>
</Problem>

<Problem num="例 1.3.2">
计算 $\lim_{x\to\infty}\dfrac{3x^3 - 2x + 1}{2x^3 + x^2 - 5}$。

<Solution>
分子分母同除以 $x^3$（最高次项）：

$$\lim_{x\to\infty}\frac{3 - 2/x^2 + 1/x^3}{2 + 1/x - 5/x^3} = \frac{3}{2}.$$

**规律**：同次取最高次系数比；分子次数高则极限为 $\infty$；分子次数低则极限为 $0$。$\blacksquare$
</Solution>
</Problem>

<Problem num="例 1.3.3">
讨论 $f(x) = \begin{cases}x+1, & x < 0 \\ 0, & x = 0 \\ x-1, & x > 0\end{cases}$ 在 $x = 0$ 处的极限。

<Solution>
$f(0^-) = \lim_{x\to 0^-}(x+1) = 1$，$f(0^+) = \lim_{x\to 0^+}(x-1) = -1$。

左右极限不等，故 $\lim_{x\to 0}f(x)$ **不存在**（跳跃间断点）。$\blacksquare$
</Solution>
</Problem>
