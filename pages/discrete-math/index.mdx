# 🔗 离散数学

离散数学是算法和计算机科学的语言基础。图神经网络（GNN）建立在图论上，密码学建立在数论上，逻辑推理建立在命题逻辑上。AI 时代不只有神经网络，离散结构无处不在。

## 核心公式速查

**鸽巢原理**：n+1 个物体放入 n 个盒子，至少有一个盒子装了 2 个物体。

**图的握手定理**

$$\sum_{v \in V} \deg(v) = 2|E|$$

**组合数**

$$\binom{n}{k} = \frac{n!}{k!(n-k)!}$$
